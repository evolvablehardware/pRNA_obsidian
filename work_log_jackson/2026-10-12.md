## Log
- I spent some time messing around with a feed forward neural network representation of the fpga architecture. In summary, a lut consists of 4xinput input determination weights. For each input, softmax(w)\*x determines the net input value. During training, the softmax temperature is lowered to converge to a single input. Each weighted input is interpreted as a probability to calculate the chance of each lut row occurring. The lut row values are just represented as 16 weights, so the final output is calculated as \sum p_row \* sigmoid(x_row). Like the input weights, the sigmoid temperature is gradually lowered to encourage convergence. To translate to the direct fpga representation, the highest weight input is used while the lut values are threshholded to 0 or 1.
